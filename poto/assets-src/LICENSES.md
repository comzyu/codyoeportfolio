# Poto assets — licences and origins

## Generated assets (everything in `/assets`)

Every asset in `/assets` is **original work, generated by the scripts in `/assets-src`** in this repository. Nothing was downloaded, sampled, traced or copied from a third party.

| Asset | Made by | Notes |
|---|---|---|
| Film looks (`assets/looks/*.cube`, `*.lut.png`, `*.json`, `grain.png`) | `assets-src/looks/generate_looks.py` | Colour maths written from scratch. Not based on, named after or matched to any film stock or camera. |
| Test images, golden images, prototype sample photos | same script | Synthetic scenes drawn in code. |
| Papers | `assets-src/papers/generate_papers.py` | Procedural noise + fibres. |
| Inks | `assets/inks/inks.json` (hand-written values) | |
| Stickers, stamp, postmark | `assets-src/stickers/build_art.py` | Original drawings defined as point lists in the script. No logos, characters or brand marks. The camera sticker is a generic box camera. |
| Typewriter illustration | `prototypes/shared/typewriter.js` → `assets-src/typewriter/export.js` | Original, generic front view; not modelled on a real machine. |
| Sounds | `assets-src/sounds/generate_sounds.py` | Synthesised from noise and sine waves. No recordings, no samples. Placeholders for Cody's own recordings. |
| Theme | `assets-src/theme/build_theme.py` from `tokens.json` | |

Third-party code used to *produce* them (not shipped): Python 3, numpy (BSD-3-Clause), Pillow (MIT-CMU / HPND), Node.js (MIT).

## Fonts (candidates — none are bundled in this repo yet)

The prototypes load some of these from Google Fonts at view time; no font file is stored here. Before a font ships in the app, download it from its official source and keep its licence file next to it in `assets/fonts/`.

What was checked on 15 Nov 2026: the licence file in the font's upstream repository was fetched and its first lines read. That confirms **which licence applies**. It is not a legal review, so every row stays **"to verify"** until Cody (or a lawyer) reads the full text — in particular the Reserved Font Name clauses.

Notes for whoever verifies:

- OFL 1.1 and Apache 2.0 both generally allow bundling a font inside an app, including a commercial one. OFL does not allow selling the font by itself, and a modified version can't use a Reserved Font Name.
- Apache 2.0 requires keeping the licence and any NOTICE file with the distribution (an in-app "Licences" screen covers this; it is in v0.3 scope).
- The preview images in this repo do **not** use DSEG7: the date stamp in previews is drawn by code as plain seven-segment bars, so the previews are a close stand-in, not the final font.
- Two stickers (`ticket`, `wish`) contain live SVG text and so depend on a font being present (IBM Plex Mono / La Belle Aurore). For the app, convert that text to outlines once the fonts are approved.
